# Credits

## Art and audio

All artwork in the game is **generated in code by this project** (`src/world/art/` and
`src/world/pixelFont.ts`): tiles, characters, buildings, props, the in-world pixel font and the
social preview image (`scripts/make-og.mjs`). No third-party sprites, tilesets, fonts or sound files
are used, so there is nothing to attribute and no asset licence to comply with.

Sound effects are short oscillator beeps synthesised at runtime with the Web Audio API
(`src/audio/`), along with the music. They stay silent until the visitor turns sound on.

Text uses system font stacks (nothing is downloaded).
